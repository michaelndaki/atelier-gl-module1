# Outils utilisés

## Python
Langage de programmation utilisé pour écrire le programme. Version : 3.12.0.

## VS Code
Éditeur de code utilisé pour écrire et organiser les fichiers du projet.

## Git
Outil de gestion de versions : il enregistre l'historique du projet sous forme de commits. Version : 2.55.0.

## GitHub
Site web qui héberge le dépôt Git en ligne et permet de le partager avec l'enseignant.
