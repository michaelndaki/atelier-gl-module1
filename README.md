# Atelier GL - Module 1

## Objectif
Prendre en main Python, VS Code, Git et GitHub en créant et en versionnant un petit projet.

## Prérequis
- Python 3.12
- Git
- VS Code
- Un compte GitHub

## Structure
- src/ : code source (main.py)
- docs/ : documentation (outils.md)
- tests/ : tests

## Exécution
py src/main.py

## Outils utilisés
- Python 3.12 : langage du programme
- VS Code : éditeur de code
- Git : gestion des versions
- GitHub : hébergement du dépôt en ligne
